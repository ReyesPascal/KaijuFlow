First baseline, 2026-11-10 (old machine, NinjaCentral only)

Kept for the record. This run was made on the old machine, with three setups and a recording that lacked the warm rounds. Its run record was lost with that machine. The 2026-11-13 run above replaces it as the baseline.

The first timed run on the test copies, the starting point that every later change is measured against. Three setups, 10 titles, four rounds: cold, warm, cold, warm. The indexer answers were recorded once and replayed to every setup, so all three searched the same NinjaCentral results. Recording 07:27 to 07:35 UTC, timed run 07:37 to 07:59 UTC. No errors and no indexer limit. The live services were not touched.

What the run found

  • KaijuFlow's one miss is a good Source that it gave up on. Oppenheimer's top pick played on Usenet Ultimate with NzbDAV. It was the same Source on both. Its release name ends in ".mkv". AltMount took it in without complaint and stored it as a folder with that name holding the file. The address KaijuFlow then asked for is the folder, not the file. AltMount answered "400" to it twice, and KaijuFlow showed the failure video and marked the Source dead. In the warm rounds the next Source played. This is the only thing between KaijuFlow and 10 of 10 in the cold rounds.
  • Where the cold list time goes. Of KaijuFlow's 10.1 s, about 1.8 s is waiting for the indexer and about 6.1 s is health checks. Usenet Ultimate's list takes the same time; it does the same work.
  • A warm list costs about 2 seconds before any checking. With the search already remembered, KaijuFlow still spent about 2 s going through a list of 300 Sources and 0.3 s on a list of 70, before any health check. Read from the log's timestamps; the cause was not looked into.
  • The Unscramble check costs time on half of the cold plays. On 5 of 10 top picks KaijuFlow spent 0.6 to 1.5 s finding out that the set needs no Unscramble. Interstellar, the one Scrambled RAR set, took 4.8 to 4.9 s to Unscramble. AltMount's import itself took 1.6 s (median).
  • AltMount's own addon fails the same picks every round. The Matrix and Game of Thrones S02E03 failed in all four rounds (HTTP 503 after AltMount's own check). It keeps no memory of a bad Source, as on 2026-11-09.

What this baseline cannot be used for yet

  • Warm list times are too low. In a warm round KaijuFlow and Usenet Ultimate leave out the Sources that failed in the cold round and health-check a few replacements. The recording was made in one cold pass, so it does not hold the files for those replacements (40 requests in the warm rounds, none in the cold rounds). Each of those checks ended at once and cost nothing. This touched 6 of 10 titles on KaijuFlow and 5 of 10 on Usenet Ultimate. The clean titles (Inception, The Dark Knight, Pulp Fiction, Breaking Bad S01E01) are right. Play counts and start times are not affected.
  • Usenet Ultimate's import time is blank. NzbDAV's log does not say when an import starts or ends, so only its start time as seen from outside is known.
  • The fourth setup was not run. "KaijuFlow, one page per indexer" was planned as a fourth side. The recording tool stopped that copy and never started it again, so it recorded nothing and was left out of the timed run.
  • One indexer only. With NinjaCentral alone the lists are about half as long as on 2026-11-09, so these numbers do not compare with the ones further down this page. Later runs have to use the same recording to compare with this one.
