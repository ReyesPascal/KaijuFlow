## Ordinary playback path

1. PTP's Details screen navigates to the player for automatic Play, or opens its source selector when automatic single-source play is off; [DetailsScreen](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/details/DetailsScreen.kt#L540-L585). The personal preference is collected into that state; [DetailsViewModel](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/details/DetailsViewModel.kt#L365-L385).
2. StreamRepository builds an addon GET `<configured-base>/stream/movie/<id>.json`, or series type/encoded ID (including episode identity), retaining existing addon query parameters; [movie request](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/repository/StreamRepository.kt#L2090-L2145), [episode request](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/repository/StreamRepository.kt#L2265-L2295). Retrofit takes the full URL; [StreamApi](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/api/StreamApi.kt#L33-L39). No new PTP-specific discovery endpoint is required by this baseline.
3. KaijuFlow mounts manifest-key protected addon routes at both `/stremio/:manifestKey` and legacy `/:manifestKey`; [server](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/server.ts#L184-L213). Its SDK stream handler owns discovery orchestration; [handler](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/addon/index.ts#L195-L205). The result pipeline removes known dead NZBs, applies configured filtering/sorting, coordinates health checks, and builds streams; [pipeline](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/addon/index.ts#L367-L455).
4. Standard NZBDav result tiles carry `name`, `title`, `url`, and `behaviorHints: {notWebReady:false,bingeGroup}`. The URL targets `<prefix>/<manifestKey>/nzbdav/stream/<filename>?t=<envelope>`. Envelope fields include fallback-group/candidate references, content/session identity and release information; they are internal preparation/fallback state, not a versioned PTP metadata contract. [builder](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/addon/streamBuilder.ts#L333-L362). Library/EasyNews paths and optional Ultimate Fallback/control tiles also exist; [builder](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/addon/streamBuilder.ts#L243-L332), [UF tile](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/addon/streamBuilder.ts#L377-L440).
5. GET on the selected tile triggers preparation, then proxy delivery or redirect. Stream handler prepares/submits/polls/discovers/probes video; [preparation](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/nzbdav/streamHandler.ts#L175-L285). Routes expose stream and video proxy entry points; [stream route](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/routes/nzbdav.ts#L523-L540), [video route](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/routes/nzbdav.ts#L1049-L1065).

## BestSourcePicker is active, with important qualifications

The personal-build automatic path is reachable: progressive source collection → `autoplaySelectBest` → `startBestSource` → `BestSourcePicker.pickIndex` → `selectStream(fromBestSource=true)`. PTP waits for the enabled Usenet Ultimate addon or search completion before choosing another provider; [collection](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerViewModel.kt#L1585-L1618), [automatic selector](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerViewModel.kt#L2807-L2823), [picker invocation](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerViewModel.kt#L8240-L8279).

**It does not re-sort the returned Usenet Ultimate list. It does select and skip candidates for automatic playback.** Recognition is by addon ID containing `usenetultimate` or addon name containing `usenet ultimate`; [identity helper](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/model/UsenetUltimateFirst.kt#L8-L20). The player sorting functions early-return that ordered subset; [sorting](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerViewModel.kt#L2944-L2952). The ingestion path still rejects unsupported/unplayable links, progressive collection excludes blank/magnet URLs and deduplicates, and startBestSource excludes blank URLs. Therefore “never filters anything” is too broad; [ingestion](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/repository/StreamRepository.kt#L3131-L3145), [collection](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerViewModel.kt#L1595-L1610).

Picker traits are parsed primarily from quality/raw labels and descriptive text, with optional filename/size hints; [parser](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/util/BestSourcePicker.kt#L71-L125). Device tests cover screen resolution, hardware codec/10-bit/UHD decoding, HDR and Dolby Vision base-layer compatibility. Audio does not disqualify. [verdict](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/util/BestSourcePicker.kt#L146-L210). It selects first suitable source, optionally advances to the preferred picture format (same resolution on a 4K TV), and when none suits uses resolution fallback ordering, including unknown resolution before lower resolutions. [fallback/preference](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/util/BestSourcePicker.kt#L216-L275). This is local compatibility selection, not proof of actual file codecs, health or successful decoding.

Retry uses `nextBestSourceAfterFailure`, tracks tried source keys and caps the best-source session at **3 sources total**; [session/retry](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerViewModel.kt#L8176-L8238), [constant](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerViewModel.kt#L8627). PlayerScreen invokes it only for an active personal best-source session; [retry caller](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerScreen.kt#L952-L998). Manual selection and scan-failure fallback do not establish that same session contract.

**Compatibility risk:** branding/manifest-ID changes must preserve recognition or deliberately revise this behavior. Source-order preservation depends on addon identity, not just “a KaijuFlow server returned streams.”

## Timeout and fallback budgets are layered

- Discovery is separate from media startup. Usenet Ultimate identity triggers PTP's extended discovery timeout: movie 30s, episode45s, individual episode request35s; [policy](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/repository/StreamRepository.kt#L1914-L1927), [recognition](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/repository/StreamRepository.kt#L2034-L2056). Movie GET is wrapped in its selected budget; [request](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/data/repository/StreamRepository.kt#L2093-L2102).
- Personal player startup has a **30,000ms minimum soft timeout**, then **12,000ms extra**, capped at45,000ms. In this snapshot the stock estimate caps below30s, so ordinary personal startup reaches a nominal42s hard watchdog. [constants/estimator](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerScreen.kt#L6880-L6933), [watchdog](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerScreen.kt#L2923-L2976). The clock is reset before prepare after subtitle work; [clock](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerScreen.kt#L2424-L2435). Explicit startup errors can trigger fallback sooner; [error handling](https://github.com/ReyesPascal/Pascal-The-Popcorn/blob/fdbe213ac1840086a01ba2bc6b007877c8babaf4/app/src/main/kotlin/com/arflix/tv/ui/screens/player/PlayerScreen.kt#L1590-L1625). Thus 30+12 is a watchdog policy, not a guaranteed minimum wait on every error or a Play-to-frame SLA.
- KaijuFlow already has a configurable first-source switch (default25s): on a fresh request with multiple eligible candidates, excluding auto-queue, it tries the next candidate while leaving the first preparing. [default](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/nzbdav/streamHandler.ts#L47-L61), [race](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/nzbdav/streamHandler.ts#L1158-L1177), [switch handling](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/nzbdav/streamHandler.ts#L1277-L1283). Post-redirect preparation races an8s request budget; Stremio's60s window and5s margin are separate server constants, with a configurable self-redirect cap default500. [constants](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/nzbdav/streamHandler.ts#L47-L50), [post-redirect](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/nzbdav/streamHandler.ts#L1144-L1158). Ultimate Fallback has mode/content-specific waits; [defaults](https://github.com/ReyesPascal/KaijuFlow/blob/6565c1a7c810e2cb2bf7d4e1239e545adbd4236e/src/nzbdav/timeoutDefaults.ts#L15-L34).
- PTP's “3 sources” and KaijuFlow's release candidate walk are independent: a single PTP tile URL can lead through multiple backend candidates. Neither three times42s nor25s alone describes end-to-end behavior.

## Evidence limits and planning implications

No installed APK/source correspondence, runtime configuration, enabled UF/control tiles, network timing, request traces or TV playback outcomes were verified. These pins establish repository behavior under guards and settings only. Do not infer deployment host, topology or performance from comments/handoff. No claim here promotes an alternative backend.

Keep KaijuFlow's discovery/health/ranking/source fallback ownership. Any new integration must preserve addon identity/ordered list semantics, clearly distinguish device incompatibility from dead NZBs, and coordinate the independent preparation and player watchdogs. A shared request ID, explicit metadata and preparation lifecycle may be useful additions, but remain unaccepted design proposals. No KaijuNNTP extraction, Brain architecture or unrelated PTP redesign is needed to record this baseline.
